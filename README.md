# JashNotesApp

JashNotesApp is my personal note-taking app built with React Native and Expo. It is designed for quick note capture, simple organization, and a clean mobile experience.

## What this app does

- Create and edit notes quickly
- Organize notes with folders and tags
- Mark favorites and keep notes locally on the device
- Run as a lightweight mobile app without needing a complex backend for the current version

## Tech stack

- React Native
- Expo
- TypeScript
- SQLite via Expo SQLite
- Zustand for app state
- React Navigation

## Current status

This project is a personal app I am building and improving over time. It is currently focused on being practical, lightweight, and easy to use on Android.

## Local setup

```bash
npm install
npx expo start
```

## Android build

```bash
eas build -p android --profile production
```
